Zyvor·Device AgentHardware layer · No K8s required

Hardware on the box. Protocols in Nodra.

A Rust daemon on Linux edge gateways: discover identity, buses, and health; run sensor plugins; expose REST and Prometheus — then hand industrial semantics to Nodra and lifecycle to Fleet.

BOOT1

Install & serve

systemd, `.deb`/`.rpm`, or multi-arch OCI on ARM64 — no Kubernetes on the device.

SCAN2

Inventory Linux

CPU, thermal, GPIO, I²C, SPI, UART, CAN, USB, watchdog — cached refresh + change events.

BUS3

Industrial posture

SocketCAN health, passive RS485 awareness, optional read-only CAN capture — no frame decoding.

SENSE4

Plugin samples

External sensor processes on a stable contract; reference LM75/TMP102 I²C temperature plugin.

INTEGRATE5

Nodra & Fleet

Retained MQTT inventory, SSE events, Fleet inventory bridge — WAN loss handled upstream in Nodra.
